#  Nova TripChat AI

An AI-powered travel planner built with Amazon Nova for the Amazon Nova Hackathon 2026.

##  Features
-  **Trip Planner** — Day-by-day itineraries for any destination
-  **Hotel Finder** — Budget, mid-range and luxury recommendations
-  **Budget Estimator** — Detailed cost breakdown for your trip
-  **Packing List** — Smart packing lists based on destination and trip type
-  **Multi-turn Chat** — Remembers your conversation context

##  Powered By
- Amazon Nova Lite (amazon.nova-lite-v1:0)
- AWS Bedrock
- Flask + Python

##  How to Run
1. Clone the repo
2. Create `.env` with your AWS credentials
3. Run `pip install -r requirements.txt`
4. Run `python app.py`
5. Open `http://localhost:5000`
